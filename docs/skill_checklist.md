如果你时间有限，按这个顺序补，性价比最高：

### 第一梯队（最该补，直接提升岗位匹配度）
1. RAG 调优：混合检索 + rerank + 召回质量评估

### 第二梯队（补上后项目更完整）
4. 多轮会话历史
5. 工具 schema + 白名单

### 第三梯队（能讲出来就加分，不强制实现）
7. Docker 化
8. 灰度发布方案
9. 安全合规条目
